SKÆRMKORT PÅ FIREBASE — uden Python
===================================

1) Firebase → tandhjul Settings → Project settings
2) Rul ned til Your apps → tilføj en Web-app (</> ) hvis der ikke er en
3) Kopiér apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId
4) Åbn filen firebase-config.js og erstat INDSÆT-felterne
5) Firestore → Rules → indsæt indholdet fra firestore.rules.txt → Publish
6) Læg ALLE filer fra DENNE mappe op i GitHub-repoet remote-menukort
   (erstat de gamle html/js)
7) GitHub → Settings → Pages → Deploy from branch main → Save
8) Åbn siden:
   https://danpay-collab.github.io/remote-menukort/admin.html
9) Tryk "Opret testkunder i databasen"
10) TV: .../display.html?id=odense

Så ligger kunderne i Firestore, og prikkerne farves efter om TV'et sender puls.
